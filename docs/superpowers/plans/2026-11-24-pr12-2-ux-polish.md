## 已決定（2026-11-24，使用者同意）

PR 12.2 做「UX 收尾」，也就是 PR 12.1「下一個 PR 需要知道的事」列的兩項：

1. 長條圖底槽（`.bar-track`）對卡片底色只有 1.19:1。
2. 「＋ 加一組」的虛線外框，和外框按鈕的邊框，仍用 `--color-border`。

## 規劃時的決定（我替你做的）

1. **底槽用 1px 內框，不改底色。** `.bar-track` 加 `box-shadow: inset 0 0 0 1px var(--color-border-strong)`。
   - 內框對外側卡片底色 ≥ 3:1（`tokens.test.ts` 已經檢查 `borderStrong` 對 surface）。
   - 填色（`.bar-fill`）蓋在內框上面，所以已填的部分看不到框，只有空的部分有框。
   - 不另外加 token，也不把底色加深，避免長條圖跟填色搶眼。
2. **外框按鈕指 `.card-links a.pill-link`**（例如「看訓練紀錄 ›」）。`button.secondary` 本來就用 `--color-primary` 當邊框，不用改。
3. **`button.tile` 不改。** 它的外型是卡片，照 PR 12.1 的原則，卡片框維持 `--color-border`。
4. **不處理** `.stepbar-track`（個人檔案步驟條）和 `.ring-track`（圓環）：前者旁邊有「步驟 N/M」文字，後者中間有數字。
