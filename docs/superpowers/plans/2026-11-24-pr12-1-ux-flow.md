# PR 12.1: LIFF 介面流程修正 Implementation Plan

**Goal:** 修 PR 12（UI 改版，[PR #31](https://github.com/papa-Zhao/gym-assistant-coach/pull/31)）之後 UX 檢視找到的流程斷點、細節與淺色模式對比問題。只動 LIFF 和 shared 的色彩 token，不動 API。

**前一份計畫：** PR 11.4。PR 12 沒有獨立計畫文件，是直接依 UI 改版需求實作（commit `9545e3b`），已經用 PR #31 合併（merge commit `5c09898`）。

**還沒做的計畫：** PR 11.2（把手）仍是「計畫，尚未實作」，本 PR 不影響它。

## 已決定（2026-11-24，使用者同意）

UX 檢視（ui-ux-pro-max）把問題分成 P0／P1／P2，使用者同意全部修，之後再修淺色模式對比。

- **P0**
  - 記訓練首頁的「開始訓練」被推到畫面外。
  - 記訓練首頁沒跟上新卡片樣式。
  - 範本列的「刪除」和「開始」一樣大。
- **P1**
  - 設定頁「訓練範本」寫即將推出，但功能已經在了。
  - 「個人檔案」和「每日目標」都落在同一頁。
  - 點心沒有入口。
  - 子頁面沒有返回入口。
  - 體脂、腰圍磁磚空的時候看不出能點。
- **P2**
  - 組數表的「休息」欄看起來空著。
  - AI 建議讀起來像在問問題。
  - 底部按鈕份量：結束是主要按鈕，加動作反而是次要。
  - 「放棄這次訓練」離標題太近。
  - 「草稿」只是文字。
- **對比**
  - 輸入框和選項外框只有 1.3:1。
  - placeholder 只有 4.28:1。
  - 淡化的「—」只有 3.0:1。

## 交接備註

- **記訓練首頁**（`WorkoutHome.tsx`）
  - 「開始訓練」放在 `.bottom-bar` 裡；`main.workout-home` 的 `padding-bottom` 預留了一個按鈕的高度。
  - 錯誤訊息也放在底部列裡，在按鈕上面。
  - 肌群依組數排序，`TOP_MUSCLES = 3`，超過 3 個才出現「看全部 N 個部位」（`aria-expanded`）。
- **範本列**
  - 整列是 `button.row.template-start`，`aria-label` 維持「開始 {名稱}」。
  - 刪除是 `.icon-btn`，`aria-label` 維持「刪除 {名稱}」，仍然要用 `ConfirmRow` 確認。
- **個人檔案**
  - `Profile` 新增 `initialStep`（預設 2），由 `App` 從 `?step=1` 讀。
  - 新使用者沒有資料時，不管參數一律從步驟 1 開始。
- **今日飲食**
  - 點心列一定顯示，空的時候寫「有吃再記」。
  - 「草稿」是 `.badge.draft-badge`。
- **返回連結**
  - `a.back-link` 加上新的 `chevronLeft` icon，目前用在身體數據和訓練紀錄頁。
  - 新的子頁面可以直接沿用。
- **訓練進行中**（`ActiveWorkout.tsx`）
  - 編輯列的休息欄顯示「自動」（`.rest-auto`），因為休息秒數是在完成那組時自動算的。
  - AI 建議在第一組前顯示「已幫你填好 X kg」（預填確實是用建議重量），已經有組之後改成「建議今天用 X kg」。
  - 底部列的順序是「結束訓練」（`secondary`，左）、「＋ 加動作」（主要，右）。
  - 放棄按鈕在 `.discard-zone`，位置在所有卡片下面。
- **對比**
  - shared 新增 `borderStrong`：淺色 `#9C8B79`、深色 `#857769`。`tokens.test.ts` 會檢查它對 bg 和 surface 都至少 3:1。
  - 只有需要看出邊界的控制項用 `--color-border-strong`：輸入框、克數步進器、選項、radio 圈、`secondary.quiet`。
  - 卡片框和分隔線維持 `--color-border`，避免畫面變重。
  - `::placeholder` 統一用 `--color-text-muted`。
- **預覽**
  - `apps/liff/preview/` 沒有進版控。`main.tsx` 改成把整串 `location.search` 傳進去，所以 `&step=1`、`&active=1` 都能用。
